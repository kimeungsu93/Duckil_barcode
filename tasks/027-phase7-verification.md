## 테스트 환경

- 서버: 스크래치에 만든 프로젝트 복제본에서 `npm run build` 후 `DATA_DIR=<스크래치>/data next start -p 3100`
  - 3000·3001번 포트에서 기존 dev 서버가 프로젝트의 `.next`를 쓰고 있어, 겹치지 않도록 복제본에서 빌드했다
- 브라우저: Playwright MCP(Chromium, 카메라 없음)
- 키보드 웨지 입력은 Playwright의 `fill` + `Enter`, 또는 한 글자씩 입력 + `Enter`로 흉내냈다
- 서버 오류·413·415는 `page.route`로 해당 요청만 가로챘다. 브라우저 저장소 차단·카메라 API 없음은 `addInitScript`로 흉내냈다

## 계획과 달라진 점

- 원본 바코드 조회 함수 이름은 `findByRawKey`가 아니라 `findByRawText`다. 원문을 받아 내부에서 `toRawKey`로 바꾼 뒤 조회한다.
- 직접 입력의 중복 확인은 원문 입력란 blur 때가 아니라 정보 확인 단계에서 [다음]을 누를 때 한다.
- 상세 화면 스켈레톤(`record-detail-skeleton.tsx`)은 바꾸지 않았다. 지금도 사진 자리를 1칸만 보여준다.
